# プラレールシミュレータ

ブラウザでプラレールのレイアウトを作成・シミュレーションできるアプリです。

※「プラレール」は、株式会社タカラトミーの登録商標です。

## Live Demo

[https://binzume.github.io/plarail-sim/](https://binzume.github.io/plarail-sim/)

## 使い方

- 左のパーツリストからパーツをドラッグしてレールや列車を追加します
- パーツをドラッグして移動し、レールを接続します(終端の雌雄を合わせる必要があります)
- レイアウトメニューからサンプルやファイルの読み込み・保存ができます
- レール終端をドラッグするとレールを自動配置して伸ばせます
- 再生ボタンで列車を走らせます
- Shift + ? できーぼどショートカットの説明が表示されます
